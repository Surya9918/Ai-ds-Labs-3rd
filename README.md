# AI & Data Science Weekly Labs 🧬📊

This repository contains my weekly laboratory coursework for the **B.E. in Artificial Intelligence and Data Science** program at Chaitanya Bharathi Institute of Technology (CBIT). 

It is divided into two primary courses, focusing on deep learning architectures and foundational data science techniques.

---

## 🧠 Advanced Artificial Neural Networks Lab (Python)


This section contains implementations of deep learning architectures for classification tasks, optimization techniques, regularization methods, and sequential models.

### 🗂️ Lab Experiments
* **`01_Single_Layer_Perceptron/`** - Implementation of a single-layer perceptron and Sigmoid for binary classification on a synthetic dataset.
* **`02_MLP_MNIST_Classification/`** - Classification using a Multilayer Perceptron with the MNIST Dataset.
* **`03_Hyperparameter_Tuning/`** - Performance comparison of classification models by tuning hyperparameters.
* **`04_CNN_MNIST/`** - Construction of a Convolutional Neural Network (CNN) for classification on the MNIST Dataset.
* **`05_Deep_Learning_Models/`** - Implementation and comparison of Deep Learning models (AlexNet, VGGNet, DenseNet).
* **`06_ResNet_GoogLeNet/`** - Implementation of ResNet and GoogLeNet for image classification.
* **`07_RNN_Text_Classification/`** - Implementation of a Recurrent Neural Network (RNN) for text classification.
* **`08_LSTM_Sentiment_Analysis/`** - Implementation of LSTM and Bidirectional LSTM for sentiment analysis.
* **`09_Encoder_Decoder_Attention/`** - Encoder-Decoder Models with attention for machine translation.
* **`10_GAN_Model/`** - Implementation of a Generative Adversarial Network (GAN).

## 📊 Introduction to Data Science Lab (R Language)


This section focuses on data structures, data preprocessing, visualization, and applying supervised and unsupervised learning algorithms using R.

### 🗂️ Lab Experiments
* **`01_R_Programming_Basics/`** - Basics of R including operators, data types, variables, and string manipulations.
* **`02_R_Data_Structures/`** - Usage of R data structures (Lists, Vectors, Matrices, Data frames, Factors).
* **`03_File_Formats_Analysis/`** - Analyzing file formats in R (CSV, TSV, Excel, XML, JSON, HTML).
* **`04_Preprocessing_Techniques/`** - Implementation of data preprocessing techniques on various datasets.
* **`05_Data_Visualization_Manipulation/`** - Data visualization and manipulation using R packages (dplyr, data.table, reshape2, tidyr).
* **`06_LIME_Importance/`** - Visualizing the importance of LIME (Local Interpretable Model-agnostic Explanations).
* **`07_Regression_Models/`** - Building and evaluating linear and logistic regression models on test data.
* **`08_Association_Rule/`** - Demonstration of Association Rule mining techniques.
* **`09_Text_Mining_Sentiment/`** - Exploration of text mining techniques and sentiment analysis.
